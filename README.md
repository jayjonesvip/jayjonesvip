# Alterworld Enterprises

Independent developer building browser games, useful web tools, and questionable ideas worth trying.

I like projects you can open in a browser and immediately do something with—build a fighter, survive a zombie outbreak, plan your draft, or mix a better BBQ rub.

[Explore the portfolio](https://www.alterworldenterprises.com/) · [Play on itch.io](https://lightningjay.itch.io/)
